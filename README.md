# The 32-Tooth Longevity Atlas — US CDC NHANES Epidemiological Scrollytelling

Interactive Long-Form Vertical Scrollytelling Dashboard & Tableau Packaged Workbook (`.twbx`) modeling tooth-by-tooth retention probability, periodontal attachment loss ($\ge 4\text{ mm}$), interdental hygiene habits, and socioeconomic preventive care barriers across ages 20 to 80+.

- **Live Web Application:** Open `index.html`
- **Tableau Packaged Workbook:** `NHANES_Dental_Longevity_Atlas_Production.twbx`
- **Data Source:** US CDC / NCHS National Health and Nutrition Examination Survey (NHANES Oral Health & Periodontal Examination Files, $N = 24,625$ respondents, $788,000$ tooth evaluations, $1,437,814$ periodontal probing sites).
